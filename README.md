# MovieDataDecoder v1.2.1

把 MovieData 导出的一部电影的影院日明细，转成 Excel，包含**逐影院票房**和**逐日明细**两个工作表。金额单位为元。

Decoder 在本地读取已采集的数据，一次转换一份选中的电影明细。表格保留所选文件中出现的全部影院，并展示每家影院在日期区间内的每天记录。需要继续采集或复核缺口时，在 MovieData 中完成后重新导出 CSV，再用 Decoder 转换。

首次使用可阅读 [使用说明](MovieDataDecoder_v1.2.1_使用说明.md)，其中包含逐步操作、筛选示例和常见问题处理。

## 功能

- 按影院汇总所选日期区间内的该片票房，同时导出影院逐日明细。
- 导入 CSV、包含影院明细的 ZIP，或 MovieData 结果文件夹。
- 区分已确认金额、完整区间金额、204、未采集、数据异常和源文件缺行。
- 根据日期与影院编码去重，冲突数据会指出源文件行号。
- 输出保留数字金额、可筛选的日期及带前导零的文本编码。
- 蓝灰表头、隔行底纹、金额加粗、状态提示、长影院名称换行，以及两个工作表间的跳转链接。
- 冻结表头和影院标识列，超过单表行数上限时自动续写工作表。

## 获取与运行

Windows 用户解压 `MovieDataDecoder_v1.2.1_win64.zip`，进入解压后的目录，双击 `MovieDataDecoder.exe`。免安装包包含运行环境。查看导出的 `.xlsx` 文件需要 Excel、WPS 等表格软件。

Windows 包包含 `MovieDataDecoder.exe`、`README.md`、`使用说明.md` 和 `XlsxWriter-LICENSE.txt`。源码包包含主程序、转换模块、依赖清单、测试及两份说明文档。

## 怎么用

1. 在 MovieData 的「全国全影院历史票房采集」中选好电影与日期，采集后点「导出当前 CSV / 审计」。
2. 解压 Decoder Windows 免安装包，双击 `MovieDataDecoder.exe`。选择 `*_cinema_days.csv`，也可以选择包含该文件的 ZIP 或结果文件夹。
3. 点「导出逐影院票房」，保存并打开 Excel。
4. 在 Excel 底部点「逐日明细」，用表头的筛选按钮选择日期或影院，即可查看这部电影在每家影院每天的票房。

文件路径显示为可横向滚动的单行，点击后可以用键盘移动光标、选择和复制完整路径。长路径与长文件名不会增加显示行数，最小窗口下也能使用导出与打开按钮。

## 输入文件与识别规则

建议直接使用 MovieData 导出的原始文件名，例如下面这份影院日明细。

```text
00103542025_2026-10-01_2026-10-07_cinema_days.csv
```

程序从文件名读取电影编码、开始日期和结束日期，日期区间包含起止两天。保留原始文件名有助于核实整段日期的完成情况。

| 选择方式 | 识别范围 |
| --- | --- |
| 直接选择 CSV | 检查必需字段。改名后的 CSV 也可单独选择 |
| 选择 ZIP | 查找压缩包各目录内以 `_cinema_days.csv` 结尾的文件 |
| 选择文件夹 | 查找所选目录、其 `national_history` 子目录和 `output/national_history` 子目录中的影院明细 |

文件夹和 ZIP 中有多份明细时，通过界面下拉框选择本次要转换的一份。每份明细对应一部电影。影院名录、审计表和 JSON 可以保留在目录内，Decoder 会识别其中的影院日明细 CSV。

### CSV 字段约定

CSV 使用 UTF-8 编码，可带 BOM。表头名称须唯一，每行列数须与表头一致。

| 字段 | 要求与用途 |
| --- | --- |
| `date` | 必需，`YYYY-MM-DD` 日期 |
| `cinema_code` | 必需，6～10 位数字影院编码，导出为文本 |
| `movie_code` | 必需，1～30 位数字电影编码，同一文件内保持一致 |
| `status` | 必需，非空采集状态，见下表 |
| `sales_fen` | 必需列，原始金额单位为分。`with_movie` 行须填非负整数，`without_movie` 行可填 0 或留空 |
| `cinema_name` | 可选，影院名称。汇总采用该影院最近有名称的日期所记录的名称 |

金额以 `sales_fen` 计算，导出时按 100 分等于 1 元转换。未核查状态的金额在 Excel 中留空。单条已确认金额最多接受 15 位整数分，超出安全精度范围的影院汇总会报错。

| 原始状态 | 含义 |
| --- | --- |
| `with_movie` | 有有效片目，包含目标电影 |
| `without_movie` | 完整片目中无目标电影 |
| `empty_204`、`deferred_204` | HTTP 204 待复核 |
| `missing` | 未采集 |
| `error` | 采集异常 |
| `inconsistent` | 数据不一致，待复核 |
| 其他非空状态 | 显示为未知状态并保留原始状态，等待复核 |

## 每天的数据怎么读

「逐日明细」按日期、影院编码排列，每家已知影院每天一行，包含日期、影院编码、影院名称、该片当日票房、采集状态、原始状态和电影编码。

| 采集状态 | 当日票房 |
| --- | --- |
| 已核查，有该片 | 当天取得的该片票房，可为 0 |
| 已核查，无该片 | 完整片目中确认无该片，填 0 |
| HTTP 204 待复核 | 留空，等待补采复核 |
| 未采集 | 留空 |
| 采集异常、数据不一致、未知状态 | 留空，并保留源状态 |
| 源文件缺行，待核查 | 区间内该影院当天没有记录，补一行并留空金额 |

例如，某影院第 1 天 123.45 元、第 2 天 25 元，逐日表会显示两行，汇总表显示 148.45 元。第 2 天如果是 204，逐日表显示空金额和待复核状态，汇总仅累计第 1 天的 123.45 元。

日明细超过 Excel 单个工作表的行数上限时，自动续写「逐日明细 2」等工作表。每张表都有筛选和冻结表头。

## 汇总表的两列金额怎么读

「逐影院票房」每家已知影院一行，按已确认的该片票房从高到低排列。

| 列 | 含义 |
| --- | --- |
| 已确认票房（元） | 该影院所有已核查日期的该片票房相加。至少有一天拿到有效片目时才填 |
| 完整区间票房（元） | 仅当该影院在文件名声明的区间内每天都已核查，才写整段区间的金额 |
| 待核查天数 | 区间内尚未确认的天数，包括 204、缺行、未采集及异常。204 另有一列计数 |

例如，两天里某家影院第 1 天已确认 350 元，第 2 天返回 204，第一列金额显示 350 元，完整区间票房留空。每天都取得有效片目且确认没有该片时，完整区间票房为 0 元。重命名过的明细文件如果缺少原始日期区间，会用文件内日期显示已确认金额，完整区间票房留空。

所有源文件里出现的影院都会保留，影院编码按文本保存以保留前导零。同一影院日的重复结果只计一次，金额或状态冲突时会报错。源数据的全国名单覆盖仍待核实。

### 完整性与去重

- 表格的影院范围由所选 CSV 中出现过的影院编码决定。要判断全国影院名单是否完整，需要核查 MovieData 的名单来源和完整性审计。
- 每家已知影院在区间内每天都有一行明细。源文件缺少某个影院日时，会显示「源文件缺行，待核查」，金额留空。
- 「完整区间票房」要求原始文件名提供有效日期区间，并且该影院每天均为 `with_movie` 或 `without_movie`。
- 同一日期、影院编码的记录，状态和有效票房一致时只计一次。状态或有效金额冲突时停止转换，提示具体文件、行号和影院编码。
- 一次转换使用当前选中的明细文件。取得补采结果后，重新选择最新 CSV 导出即可。

### 输出与保存

默认文件名为 `<电影编码>_<开始日期>_<结束日期>_逐影院票房.xlsx`，其中包含汇总与逐日明细。界面导出时可选择保存目录和名称。

工作簿先在输出目录下的临时文件夹中生成，成功完成后替换目标文件。正常完成或程序捕获到转换错误时会清理临时文件。目标 Excel 正在被其他软件占用时，关闭该文件或改用新的输出文件名后重试。

每张工作表最多包含 1,048,570 行数据，另外 6 行用于标题、说明和表头。超出时自动生成「逐影院票房 2」或「逐日明细 2」等续表。

## 源码运行

需要 Python 3.10+ 和 Tkinter。

在源码目录中打开终端并执行。

```powershell
python -m pip install -r requirements.txt
python app.py
```

### 命令行转换

```powershell
python decoder.py "D:\电影结果\national_history.zip" --list
python decoder.py "D:\电影结果\national_history.zip" --select 1 -o "D:\电影结果\逐影院票房.xlsx"
python decoder.py "D:\电影结果\00103542025_2026-10-01_2026-10-07_cinema_days.csv" -o "D:\电影结果\逐影院票房.xlsx"
```

| 参数 | 含义 |
| --- | --- |
| `input` | CSV、ZIP 或文件夹路径 |
| `--list` | 列出识别到的影院明细及编号 |
| `--select N` | 选择编号 N，编号从 1 开始，默认第 1 项 |
| `--output` / `-o` | 输出 `.xlsx` 路径，父文件夹须已存在 |

省略 `-o` 时，命令行将文件保存到当前工作目录。目标文件已存在时，转换成功后会替换它。需要保留旧结果时，指定新的输出文件名。

### 测试与 Windows 构建

```powershell
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name MovieDataDecoder app.py
```

构建成功后的程序位于 `dist/MovieDataDecoder.exe`。将它与 `README.md`、`使用说明.md` 及 XlsxWriter 的许可证一起打包。Windows EXE 应在 Windows 环境中构建。

v1.2.1 已完成 8 项自动化测试、真实导出数据核对、两个工作表的可视检查，以及 Windows 解压后启动检查。测试覆盖逐影院与逐日金额、空值和零值、缺行、重复冲突、续表、文件识别及长路径界面。
